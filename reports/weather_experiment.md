# 날씨 효과 미리 보기 실험 (2026-11-17)

기상청 키를 받기 전에, 키가 필요 없는 공개 기상 재분석 자료(Open-Meteo, 제주 4지점 평균)로
"날씨를 붙이면 예측이 얼마나 좋아지는지"를 먼저 확인했습니다. **대회 제출 모델의 날씨는 기상청 데이터로 바꿀 예정**입니다.
실행: `python experiments/weather_effect.py`

## 1. 날씨와 잉여전력의 관계 (6~9월 제외)
| 한낮(10~14시) 구름양 | 잉여일 비율 | 날 수 |
|---|---|---|
| 맑음 (0~3) | 43.8% | 137 |
| 구름 (4~7) | 24.7% | 150 |
| 흐림 (8~10) | 10.2% | 246 |

맑은 날 중 **주말·공휴일은 66.7%(42일)**, 평일은 33.7%(95일)가 잉여일이었습니다.

## 2. 성능 비교 (2026년 시험 기간, 학습에 쓰지 않음)
| 변수 | 날짜 PR-AUC (고정 / 월별 재학습) | 시간 PR-AUC (고정 / 월별 재학습) |
|---|---|---|
| 달력·최근 경향 (현재 1차 모델) | 0.392 / 0.365 | 0.258 / 0.251 |
| + 일사·구름 | 0.596 / 0.567 | 0.427 / 0.402 |
| + 일사·구름·기온 | 0.633 / 0.629 | 0.447 / 0.443 |
| + 날씨 전체 (일사·구름·한낮/새벽 풍속·기온·강수) | **0.680 / 0.663** | **0.547 / 0.529** |
| + 단기예보에 있는 형태만 (하늘상태 3단계·기온·풍속·강수, 일사 제외) | 0.619 / 0.613 | 0.477 / 0.466 |

- 날씨 전체 모델(월별 재학습)의 기준값 0.3에서: 날짜 정밀도 0.60, 재현율 0.66
  (1차 모델은 0.35 / 0.40)
- 1차 모델이 놓쳤던 **2026년 10월**: 실제 잉여일의 평균 예측확률 0.05 → **0.40**
- 중요한 변수: 시각 > 한낮 일사 > 기온 > 한낮 풍속 > 한낮 구름

## 3. 해석과 주의
- 이 실험은 **실제로 관측된(재분석) 날씨**로 평가했으므로 '날씨를 완벽히 알 때'의 상한에 가깝습니다.
  실제 서비스는 **예보**를 쓰므로 내일(1일 앞)은 이에 가깝고, 3~5일 앞은 더 낮아질 수 있습니다.
- 기상청 단기예보에는 일사가 없습니다. 일사를 빼고 예보에 있는 형태로만 학습해도 날짜 PR-AUC 0.61 수준이었습니다.
- 이 결과를 반영해 `features.py`에 **하루 요약 날씨 변수**(한낮 하늘상태·풍속, 새벽 풍속, 평균기온, 강수 시간)를 추가했습니다.
  기상청 관측을 받으면 `train.py`가 자동으로 이 변수까지 학습합니다.
