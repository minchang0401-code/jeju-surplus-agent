## 3. 화면에서 보면 좋은 곳
- **5일 예보 카드 + 📊 시간대별 그래프 카드:** 그래프를 누르거나 끌어서 시각을 바꾸면 '⚡ 잉여 예보 지도' 색이 바뀌고, 카드 제목 줄에 고른 시각과 추천 시간대가 나옵니다. 1~2일 뒤는 단기예보, 3~5일 뒤는 중기예보 기준입니다.
- **🔌 충전소 지도 → 📍 내 주변 충전소:** 위치를 허용하면 내 위치로 확대, 제주 밖(육지)이면 빨간 안내와 함께 저장한 동네 기준으로 보여 줍니다.
- **👤 내 정보 (오른쪽 맨 위):** 동네·차를 저장한 뒤 "충전소 어디 있어?"만 물어도 그 동네로 찾습니다.
- **근거 보기:** 답마다 어떤 도구·데이터를 썼는지, 표·그래프·지도.

## 4. 직접 실행 (선택, 5분)
1. Python 3.11 이상 설치(윈도우는 설치 때 "Add python.exe to PATH" 체크)
2. 압축을 풀고 **윈도우 `실행하기.bat` / 맥 `실행하기.command`** 더블클릭 → 브라우저가 열립니다.
3. **키가 없어도 실행됩니다.** 이때는 규칙 기반(비상 모드)으로 답하고 저장된 예보를 씁니다.
4. **평가용 Gemini 키가 ZIP 안 `eval.env`에 들어 있어, 따로 설정하지 않아도 Gemini(AI 모드)로 답합니다.** 사용량 제한을 걸어 둔 평가 전용 키이며 심사가 끝나면 삭제합니다. 머리말에 'AI 비상 모드'가 보이면(한도 초과 등) 규칙 기반으로 답하는 상태입니다. 다른 키를 쓰려면 `.env.example`을 `.env`로 복사해 넣으면 `.env`가 우선합니다.
5. 자동 시험: `pip install -r requirements-dev.txt` 후 `python -m pytest` → 137개, 키·인터넷 없이 수 초
