# 심사위원 빠른 확인 안내

2026-11-19 최종 코드 기준입니다. 이 앱은 SMP 0원 이하 가능성을 생활 일정과 연결하며 실제 잉여 전력량·요금 할인·전력 제어를 보장하지 않습니다.

## 1 실행

프로젝트 전체와 Python 3.11 이상을 준비합니다. Windows `실행하기.bat`, macOS `실행하기.command` 또는 [설치 매뉴얼](manual.md#2-설치와-실행)의 가상환경 명령으로 실행합니다. 기본 주소는 `http://localhost:8501`입니다.

저장된 데이터·모델이 있으면 키 없이 규칙 기반 체험이 가능합니다. `.env.example` 기본 공급자는 `none`입니다. 외부 LLM은 선택한 공급자·키·모델을 별도 설정해야 하며 `eval.env`는 Git에 포함되지 않습니다. 지도 배경 등 외부 자원은 네트워크에 의존합니다.

## 2 3분 체험

1. 환영 팝업에서 설정하거나 ‘바로 둘러보기’를 누릅니다. X로 닫기·다시 보지 않기·사이드바 다시 열기를 지원합니다.
2. 날짜를 바꿔 해당 날짜의 추천 요약을 확인하고 그래프를 눌러 지도 시각을 바꿉니다. 지도 색은 제주 전체 예측, 원 크기는 권역 설비 규모입니다.
3. ‘내 생활 설정’에서 동네·차종·외출시간을 바꾼 뒤 ‘생활 계획’에 질문합니다.
4. 답변 아래 ‘근거 보기’에서 도구·데이터·응답 방식을 확인합니다. 유효한 일정이면 캘린더 저장 링크와 ICS 파일이 표시됩니다.

| 질문 | 확인할 동작 |
|---|---|
| 이번 주에 빨래랑 식기세척기 언제 돌리면 좋아? | 기기별 연속 사용 계획·가능성·예약 방법·근거 |
| 9시 출근 6시 퇴근인데 전기차 언제 충전해? | 외출 제약 반영, 집과 목적지 충전 구분 |
| 전기차 90% 남았어 충전 언제 해? | 계산 목표 80% 이상이면 불필요한 충전 일정 생성하지 않음 |
| 노형동 근처 급속 충전소 알려줘 | 동네 기준 충전소 탐색, 과거 이용 이력과 실시간 상태 구분 |
| 12월 25일에 빨래하려고 | 현재 예보 범위 밖 날짜를 임의 예측하지 않음 |

## 3 검증 근거

- `python -m pytest`: 최종 수정본 178개 통과. 검사 의존성은 `requirements-dev.txt`.
- `python run_scenarios.py`: 규칙 기반 질문 58/58, 후속 8/8, 생활 언어 10/10, 통합 5/5 확인. 실행 시 보고서를 갱신합니다.
- 저장된 모델·LLM 평가는 `reports/report.md`, `reports/llm_eval.md`. 과거 평가이며 최신 전처리·로직 수정 후 동일 시험을 모두 재실행했다는 의미는 아닙니다.
- ‘데이터 및 연결 상태’의 ‘설정됨’은 등록 여부입니다. 실제 AI 호출 성공은 질문 결과의 응답 방식과 오류 기록으로 확인합니다.

전체 사용법은 [매뉴얼](manual.md), 예측·데이터·게스트 보관·센터 실행 제약은 [오류·제약사항](troubleshooting.md)에 있습니다.
