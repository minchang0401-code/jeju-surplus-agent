# 오류 해결과 제약사항

기준: 2026-11-19 최종 코드. 설치와 기본 조작은 [사용자 매뉴얼](manual.md)에 있습니다. 문의할 때는 운영체제·Python 버전·실행 명령·오류 종류를 전달하고, 인증키·환경변수 전체·키가 포함된 요청 URL은 공유하지 마세요.

## 1 설치와 실행 오류

| 증상 | 확인 및 조치 |
|---|---|
| Python을 찾지 못함 / 버전 부족 | Python 3.11 이상인지 `python3 --version` 또는 `py -3 --version`으로 확인. 최종 회귀검사는 Python 3.14.4에서 수행 |
| `ModuleNotFoundError` | 앱을 실행하는 가상환경 Python의 `-m pip install -r requirements.txt`로 설치. 테스트는 `requirements-dev.txt`도 설치 |
| 업데이트했는데 패키지가 부족함 | 더블클릭 실행기는 기존 `.venv`의 의존성을 다시 설치하지 않음. 같은 가상환경으로 설치 명령을 다시 실행 |
| PowerShell 활성화 스크립트가 차단됨 | 정책을 바꾸지 않고 `.\.venv\Scripts\python.exe -m streamlit run app.py` 사용 |
| `Port 8501 is already in use` | 기존 앱이 실행 중인지 확인. 해당 서버에서 종료하거나 새 실행에 `--server.port 8502` 지정 |
| 코드를 수정했는데 이전 화면 | 브라우저 새로고침 후에도 같으면 서버를 종료하고 재시작. 올바른 프로젝트 폴더·포트인지 확인 |
| 모델 읽기 경고·첫 실행 지연 | 저장 모델 버전 차이로 자동 재학습할 수 있음. `requirements-tested.txt`와 데이터·디스크 쓰기 권한 확인 |
| 재학습 실패 / 학습 자료 없음 | 프로젝트 전체와 `data/`, `models/` 포함 여부 확인. 필요한 학습 자료를 준비한 뒤 `python train.py`. 데이터 없이 모델만 자동 복구되지는 않음 |

## 2 연결과 데이터 오류

| 증상 | 확인 및 조치 |
|---|---|
| AI 응답 ‘미설정’ / `fallback` | `LLM_PROVIDER=none`이거나 키가 없을 수 있음. 의도한 API 없는 체험이면 정상 |
| ‘설정됨’인데 실제 LLM 실패 | ‘설정됨’은 등록 여부. 질문 후 ‘근거 보기’의 응답 방식과 `llm_error` 확인 |
| LLM `429` | 계정·프로젝트의 요청 한도 확인. 재시도 중 지연될 수 있고 최종 실패하면 규칙 기반 응답. 한도량·초기화 시각은 제공처 기준 |
| LLM `401` / `403` | 키 유효성·선택한 공급자·프로젝트와 모델 접근 권한 확인 후 재시작 |
| LLM `400` / `404` | `LLM_MODEL`이 해당 공급자에서 사용 가능한 모델명인지 확인. 코드 기본값의 현재 제공 여부를 보장하지 않음 |
| `.env`를 바꿔도 AI가 꺼져 있음 | 프로세스의 `LLM_PROVIDER`가 먼저 적용되는지 확인. 기존 셸 설정을 조정하고 서버 재시작 |
| `eval.env` 키가 적용되지 않음 | `.env`나 프로세스에 같은 이름의 값이 있으면 빈 값도 우선. 평가용 파일은 Git에 없으며 별도 제공된 경우만 존재 |
| 기상예보 ‘갱신 실패’ / ‘저장 자료’ | 인터넷·인증키·단기/중기 각각의 활용신청 확인. 저장된 발표 시각·예측 근거를 보고 최신 예보로 오해하지 않기 |
| `SERVICE_KEY_IS_NOT_REGISTERED` | Decoding 일반 인증키, 활용신청 승인과 제공처 반영 상태 확인. 임의로 키를 로그에 출력하지 않기 |
| 최근 전력가격 부족 안내 | SMP 기준일과 누락을 확인하고 필요 시 `python collect_smp.py` 실행. 기상예보 갱신과 SMP 갱신은 별개 |
| 허브 수집 자료가 없음 | 프로젝트키와 해당 데이터 등록·접근 권한 확인. 수집기 `--help`로 선택·기간 옵션 확인. 호출 한도는 데이터 제공처 기준 |

## 3 화면과 이용 오류

| 증상 | 확인 및 조치 |
|---|---|
| 지도 배경이 비거나 카카오맵이 안 뜸 | 네트워크·차단 정책·JavaScript 키와 실제 Web 도메인 확인. 키가 없거나 로드 실패 시 Leaflet/OpenStreetMap, 타일 실패 시 Esri 대체를 시도하지만 외부 자원 전체 차단 시 표시가 제한됨 |
| 주변 위치를 못 찾음 | 사용자가 브라우저 위치를 허용했는지 확인. 원격 접속은 HTTPS 등 보안 조건 확인. 거부·실패·제주 밖이면 저장 동네 등 대체 기준 사용 |
| 안내 팝업이 안 뜸 | ‘다시 보지 않기’일 수 있음. 사이드바의 ‘처음 이용 안내 다시 보기’ 사용 |
| 다시 보지 않기가 유지되지 않음 | 비공개 모드·저장소 차단·브라우저 데이터 삭제 여부 확인. 저장소 사용 불가 시 현재 접속 동안만 유지 |
| 생활 설정·대화가 사라짐 | 게스트 세션은 영구 보관하지 않음. 새 세션·재접속·서버 재시작 시 유지 보장 없음 |
| 외출시간 변경이 반영되지 않음 | 귀가가 출발보다 늦어야 함. 잘못된 범위는 안내 후 이전 유효 일정 유지. 현재 설정은 자정을 넘는 일정 미지원 |
| 날짜를 골랐는데 추천 없음 | 해당 날짜의 남은 연속 3시간 평균 가능성이 화면 기준 20%에 못 미칠 수 있음. 다른 날짜를 선택하거나 기기별 계획을 질문 |
| 캘린더 버튼이 없음 | 일정 계획이 없는 설명 답변·예보 범위 밖·추가 충전 불필요·이미 지난 일정 등에는 저장 후보가 없음 |
| 캘린더에서 알림이 안 옴 | ICS를 캘린더 앱에 실제 가져왔는지 확인. ICS는 10분 전 알림 포함, Google은 사용자 알림 설정 적용. 서비스 자체 알림 발송 없음 |
| 좁은 화면에서 대화 패널이 아래에 있음 | 반응형 정상 동작. 태블릿 이하 폭은 지도와 대화 패널을 위아래로 배치. 날짜 버튼은 가로로 스크롤 가능 |

## 4 분석과 서비스의 제약

1. 예측은 오늘부터 5일 뒤까지만 제공하며 범위 밖의 날짜를 예보하지 않습니다. 과거 같은 달 통계가 제시되어도 그 날짜의 예측은 아닙니다.
2. SMP 0원 이하 발생 가능성을 잉여의 대리 신호로 사용합니다. 실제 잉여량·출력제어량·가구별 요금 할인·사업 참여 보상을 계산하거나 보장하지 않습니다.
3. 단기예보 값이 충분하면 날씨 모델, 중기예보만 있으면 중기 모델, 날씨가 부족하면 달력·최근 경향 모델의 참고치를 사용합니다. 날짜에 따라 자동 선택하며 ‘1~2일은 반드시 단기, 3~5일은 반드시 중기’로 고정되지 않습니다.
4. SMP나 최근 경향이 누락되면 결측을 실제 0원·잉여 없음으로 단정하지 않고 참고 예측임을 안내합니다. 자료 부족은 모델의 신뢰도 한계이며 안내 문구가 정량적인 오차 보장은 아닙니다.
5. 지도 색은 제주 전체 예측입니다. 지역별 원 크기는 설비 규모이며 읍면동별 수급·전력 배분 계산 결과가 아닙니다. 풍력 위치 일부는 대략 좌표입니다.
6. 과거 충전 이력은 기간·표본·충전소 연결 범위가 제한됩니다. 추천은 현재 빈자리·고장·이용 가능 시간·실시간 대기나 최신 이용요금 확인을 대신하지 않습니다.
7. 기기별 전력량·소요시간은 대표값입니다. 전기차는 차종 미설정 시 64.8kWh, 현재량 미입력 시 50%, 계산 목표 80%, 완속 7kW·급속 50kW 등을 가정합니다. 실제 충전 곡선·손실·기기 상태는 다를 수 있습니다.
8. 화면 외출 설정은 같은 날 출발·귀가의 평일 일정입니다. 예약 가능성은 기기 사전 기준이며 실제 제품의 기능·안전 조건은 사용자가 확인합니다.
9. 자동 검사는 코드 동작을 검증하며 실제 LLM 응답 품질이나 장기 예측 성능을 입증하지 않습니다. 기존 Gemini 27문항 기록은 최종 로직 변경 후 전체 재시험 기록이 아닙니다.
10. 저장된 PR-AUC는 관측 날씨 기반 과거 평가입니다. PR-AUC를 정확도와 혼용하지 않으며 최신 전처리 변경 후 재학습·재평가 및 실제 발행 예보 누적 검증이 필요합니다.
11. ‘지난 예보 맞았어?’는 대상 시간 시작 전 발행, 실제값·예보가 하루 24시간 모두 있는 날짜를 비교합니다. 적격 운영 로그가 부족하면 과거 시험기간 재현 결과를 구분해 안내하고, 자료가 부족하면 오류를 반환합니다.
12. 실제 사용시간 이동·출력제어 감소·배출량 감소·요금 절감은 아직 실증하지 않았습니다. 소셜 로그인·계정 보관·설비 자동 제어·충전 예약·전력 거래·에너지저장장치 배분 모의실험은 현재 구현 범위에 없습니다.

## 5 운영 전 확인할 항목

센터 PC의 실행시간·메모리·동시 사용자 성능, 외부 API의 권한·한도·실패 전환, 데이터 이용조건과 갱신 주기, 지도·위치 접근 정책을 점검해야 합니다. 문서의 ‘지원’과 특정 센터 환경에서의 실측 완료를 구분하세요.
