## 2. 정답(라벨) 정의
- 제주 시간별 SMP가 **0원 이하**인 시간 = 잉여전력 시간 (`config.SURPLUS_THRESHOLD_WON`)
- 전력거래소 시각은 구간의 끝: '13시' = 12:00~13:00 (공공데이터포털 15150712 설명으로 확인)
- 2024-06-01 ~ 2026-11-17(900일): 잉여 347시간, 127일
- 학습·평가에 쓴 기간은 '최근 경향' 변수 계산에 필요한 앞 5일을 뺀 2024-06-06부터: 잉여 339시간 (시험 기간 2026-01-01 ~ 2026-11-17: 133시간, 53일)
- EPSIS 원자료(900일)와 동봉한 요약본(`data/smp_jeju_surplus_compact.txt`)의 잉여 시간이 일치하는지 대조함 (불일치 0건)

## 3. 데이터 연결(조인) 방법
| 데이터 | 연결 키 | 처리 |
|---|---|---|
| SMP ↔ ASOS | 날짜 + 시각 | ASOS 0시 관측 → 전날 24시로 맞춤, 4지점(184·185·188·189) 평균 |
| SMP ↔ 단기예보 | 날짜 + 시각 | 제주시·서귀포 격자 평균, 하늘상태 SKY 1/3/4 |
| SMP ↔ 허브 579 | 날짜 | 지점들을 섬 평균으로 묶어 `hub_day_*` 변수 (평균기온·최고기온·강수량·평균풍속) |
| 허브 579 이후 기간 | 날짜 | 579가 끝난 2025-03-31부터는 ASOS 관측으로 같은 의미의 하루 값을 계산해 채움 (`features.hub_like_daily`). 예보할 때는 단기예보로 같은 값을 계산 |
| 허브 862 ↔ 1225 | 충전소 이름 | 동네 검색 결과에 2022년 대기 발생 비율·관광객 비중 붙임 |
| 동네 이름 ↔ 허브 862 | 위도·경도 | 동네 대표 좌표(51곳)에서 반경 2km(읍·면은 4km) 안의 충전소, 제주 밖 좌표는 제외 |
| 허브 1226 ↔ SMP | 시각 | 도민 충전 시각 분포와 잉여 시각 분포 비교 |
| 허브 1226 ↔ 862 | 충전소 이름 (398곳 중 359곳 일치) | 충전소별 낮(10~15시) 충전 횟수 ÷ 지금 충전기 수 → 한산·보통·붐빔 → 충전소 추천 순서 |
| SMP ↔ 전력수요·연계선(11~13) | 날짜 + 시각 | 세 파일 모두 '13시 = 12~13시' 구간 끝 표기라 그대로 맞춤. 연계선은 #1~#3 합계, 음수 = 육지로 역송. 낮 11시~오후 2시 평균을 잉여 있는 날과 다른 날로 나눠 비교 (`grid.py`) |
| 출력제어(11) ↔ SMP | 시각 | 기간이 겹치지 않아(출력제어 ~2024.6, SMP 2024.6~) 시각별 분포의 모양만 비교 |

## 4. 만든 변수
| 묶음 | 변수 | 출처 |
|---|---|---|
| 달력 | 월, 연중일(sin·cos), 요일, 주말, 공휴일, 쉬는 날, 시각(sin·cos) | 날짜, `config.HOLIDAYS` |
| 최근 경향 | 최근 14일 잉여일 수, 같은 시각 잉여 시간 수 (5일 전까지만 사용: 예보 시점에 알 수 있는 값) | SMP |
| 시간 날씨 | 기온, 풍속, 하늘상태, 강수 | ASOS(학습) / 단기예보(예보) |
| 하루 날씨 | 한낮(11~15시) 하늘·풍속, 새벽 풍속, 평균 기온, 비 온 시간 | 위와 같음 |
| 허브 날씨 | `hub_day_*` (일 단위) | 허브 579 |

## 5. 품질 점검
- 빠진 시간: SMP는 날짜×24시간이 모두 있는지 확인, 없으면 해당 날짜 제외
- 미래 정보 새는 것 막기: 최근 경향은 5일 이상 지난 값만, 시험 기간(2026년)은 학습에 쓰지 않음
- 학습과 실제 사용의 차이: 학습은 관측 날씨, 실제 예보는 예보 날씨 → 지난 예보를 `data/forecast_log.csv`에 쌓아 실제 성능을 따로 확인(도구⑥)
- 허브 579의 최대풍속은 순간풍속(돌풍) 값이라 다른 자료와 뜻이 달라 변수에서 뺌

## 7. 분석 흐름
```
수집 (collect_smp / collect_hub / collect_weather, prepare_files)
  → 정리·연결 (features.py: 시각 맞추기, 지점 평균, 579 이후 기간 대체)
  → 학습·평가 (train.py: 1차 모델·날씨 모델, 고정/월별 재학습, 기준선 2개와 비교 → reports/report.md)
  → 예보 (predict.py: 오늘~5일 뒤, 단기예보가 있는 날은 날씨 모델, 단기예보가 없고 중기예보가 있는 날은 중기 모델, 둘 다 없으면 1차 모델로 참고치)
  → 도구 11개 (tools.py, 기기 사전 appliances.py, 계통 기록 grid.py) → 에이전트 답변 (agent.py) → 화면 (app.py)
```
