# 설치·실행 및 사용자 매뉴얼

기준: 2026-11-19 최종 코드. 서비스명은 ‘제주 잉여전력 도우미’입니다. 저장된 데이터·모델로 게스트 체험을 시작하고 필요한 API만 연결할 수 있습니다. 오류 해결과 해석상 한계는 [오류·제약사항](troubleshooting.md)을 참고하세요.

## 1 준비물과 실행 범위

| 항목 | 기준 |
|---|---|
| Python | 코드의 최소 기준 3.11 이상. 최종 회귀검사는 macOS / Python 3.14.4 |
| 파일 | `app.py`만이 아니라 프로젝트 전체. `data/`, `models/`, `components/`, CSS와 Python 모듈 포함 |
| 실행 패키지 | `requirements.txt`. 최종 검사 버전은 `requirements-tested.txt` |
| 인터넷 | 최초 패키지 설치, 데이터 갱신, 외부 LLM, 지도 배경·길찾기·Google Calendar에 필요 |
| API 없는 체험 | 저장된 데이터·모델과 규칙 기반 답변. 지도 배경은 오프라인 지원을 보장하지 않음 |
| GPU | 학습·추론은 CPU 사용. 로컬 대형언어모델은 탑재하지 않음 |
| 센터 환경 | i7-8700 / RAM 32GB / GTX 1060·VRAM 3GB를 고려한 구성. 해당 PC의 속도·메모리·동시 이용 성능은 별도 측정 필요 |

Windows·Linux 실행 절차는 아래에 제공하지만 최종 화면·회귀검사와 모든 운영체제의 실제 검증은 구분합니다. 첫 실행 시간은 설치·데이터·모델 상태에 따라 달라지며 고정된 완료 시간을 보장하지 않습니다.

## 2 설치와 실행

### 2-1 명령어 실행

프로젝트를 내려받아 압축을 푼 폴더의 터미널에서 시작합니다. Git 사용자는 저장소를 clone한 폴더에서 실행하세요.

macOS / Linux:

```bash
python3 --version
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py --browser.gatherUsageStats false
```

Windows PowerShell:

```powershell
py -3 --version
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py --browser.gatherUsageStats false
```

PowerShell 명령은 가상환경 활성화 스크립트가 필요하지 않습니다. 패키지는 앱을 실행할 Python에 `python -m pip`로 설치합니다. `http://localhost:8501`을 열고, 종료할 때는 실행 터미널에서 `Ctrl+C`를 누릅니다. 다른 포트는 실행 명령 끝에 `--server.port 8502`를 붙입니다.

LLM을 끄고 실행하려면 macOS/Linux는 `LLM_PROVIDER=none python -m streamlit run app.py`, PowerShell은 `$env:LLM_PROVIDER = "none"`을 지정한 뒤 실행하세요. 기존 셸에 설정한 값은 새 `.env`보다 우선하므로 API를 켤 때 이 값도 확인해야 합니다.

### 2-2 더블클릭 실행

Windows는 `실행하기.bat`, macOS는 `실행하기.command`를 사용합니다. Python은 미리 설치되어 있어야 합니다. 실행기는 최초에 `.venv`를 만들고 실행 패키지를 설치한 뒤 Streamlit을 시작합니다. 서버 터미널을 닫으면 앱도 종료됩니다.

기존 `.venv`가 있으면 실행기는 패키지 설치를 건너뜁니다. 코드를 업데이트한 뒤에는 2-1의 해당 가상환경 Python으로 `-m pip install -r requirements.txt`를 다시 실행하세요. 운영체제에서 실행이 차단되면 배포 출처와 조직의 실행 정책을 확인하고, 터미널에서 2-1 절차를 사용하세요.

## 3 환경변수와 API 설정

### 3-1 예시 파일 복사

macOS/Linux는 `cp .env.example .env`, PowerShell은 `Copy-Item .env.example .env`로 복사합니다. 파일은 `config.py`와 같은 프로젝트 루트에 둡니다. Finder 숨김 파일 표시는 `Command+Shift+.`입니다.

| 변수 | 역할 | 필요 시점 |
|---|---|---|
| `LLM_PROVIDER` | `none`, `gemini`, `openai`, `upstage`, `anthropic` | 기본 `none`. LLM 사용 시 공급자 변경 |
| `LLM_API_KEY` | 선택한 공급자의 인증키 | LLM 실제 호출 |
| `LLM_MODEL` | 공급자 모델명. 공란이면 `config.py`의 기본값 | 계정에서 사용할 수 있는 모델 선택 |
| `JEJU_DATAHUB_PROJECT_KEY` | 프로젝트에 등록한 579·862·1225·1226 접근 | 허브 데이터 새 수집 |
| `KMA_APIHUB_KEY` | 기상청 API허브 ASOS 시간자료 인증 | 과거 관측 새 수집 |
| `DATA_GO_KR_KEY` | 공공데이터포털 기상청 일반 인증키(Decoding) | 단기·중기 기상예보 갱신 |
| `KAKAO_JS_KEY` | 카카오맵 JavaScript 키 | 선택적 지도 배경 |

변수 값은 예시 파일에 비워 두며 실제 키를 README나 소스에 적지 않습니다. LLM 키·데이터 키와 `.streamlit/secrets.toml`은 비공개로 관리합니다. 카카오 JavaScript 키는 브라우저가 사용하는 키이므로 서버에서만 비밀로 숨겨지는 키와 다릅니다. 허용 Web 도메인을 제한하세요.

### 3-2 읽기 순서와 재시작

일반 `.env` 로더의 우선순위는 프로세스 환경변수 → `.env` → 별도로 제공된 `eval.env`입니다. 이미 있는 키를 덮어쓰지 않으므로 빈 문자열도 우선합니다. 예를 들어 `.env`의 빈 `LLM_API_KEY=`는 `eval.env`의 같은 키 사용을 막습니다. 다른 파일의 값을 사용하려면 앞선 설정에서 해당 항목을 제거하고 새 프로세스로 시작하세요.

`eval.env`는 있을 때만 읽는 평가용 보조 파일입니다. Git에는 포함되지 않으며 평가 키의 자동 제공·유효성·한도를 보장하지 않습니다. 키를 수정한 뒤에는 브라우저 새로고침만 하지 말고 서버를 종료한 뒤 다시 실행하세요.

### 3-3 공급자와 데이터 접근 준비

- LLM: 선택한 공급자의 개발자 콘솔에서 키와 이용 가능한 모델명을 확인합니다. Gemini 설정의 코드 기본값은 `gemini-3.5-flash-lite`이며 현재 계정에서 사용할 수 없으면 `LLM_MODEL`로 변경합니다. 비용·한도·초기화 시각은 계정과 제공처 정책을 확인하세요.
- 제주데이터허브: [제주데이터허브](https://jejudatahub.net)에서 해당 데이터를 프로젝트에 추가한 후 프로젝트키를 사용합니다.
- ASOS: [기상청 API허브](https://apihub.kma.go.kr)의 지상관측 시간자료 접근 권한을 확인합니다.
- 예보: [공공데이터포털](https://www.data.go.kr)의 기상청 단기예보·중기예보 조회서비스를 각각 활용신청하고 같은 일반 인증키의 Decoding 값을 설정합니다.
- 지도: [카카오 개발자](https://developers.kakao.com)에서 JavaScript 키와 Web 도메인을 설정합니다. `localhost`와 `127.0.0.1`, 포트·배포 주소 등 실제 접속 주소를 확인합니다.

### 3-4 Streamlit Secrets

앱은 Streamlit Secrets의 `DATA_GO_KR_KEY`, `KMA_APIHUB_KEY`, `LLM_PROVIDER`, `LLM_API_KEY`, `LLM_MODEL`, `KAKAO_JS_KEY`를 비어 있는 프로세스 설정에 반영합니다. 허브 수집용 `JEJU_DATAHUB_PROJECT_KEY`는 CLI에서 프로세스 환경변수나 `.env`로 설정하세요. 배포 플랫폼의 Secrets 사용 절차에 맞게 이름과 값을 등록하고 앱을 재시작합니다. Secrets 파일을 공개 Git에 넣지 마세요.

### 3-5 실제 연결 확인

‘데이터 및 연결 상태’의 ‘설정됨’은 연결 성공 검사가 아니라 등록 여부입니다. AI는 질문을 실행하고 ‘근거 보기’의 ‘응답 방식’에서 ‘AI(LLM)’ 또는 ‘규칙 기반(비상 모드)’를 확인합니다. 코드의 응답 모드 값은 각각 `llm`, `fallback`입니다. `llm_error`가 있으면 LLM 요청 실패 후 기본 방식으로 답한 상태입니다. 기상 API는 갱신 결과·발표 시각을 확인합니다. 키 등록과 기능 실행 성공을 구분하세요.

## 4 사용자 매뉴얼

### 4-1 게스트와 이용 안내

처음 접속하면 게스트 세션이 준비되고 ‘제주 잉여전력 도우미에 오신 걸 환영해요!’ 안내가 열립니다. 소개 → 내 생활 설정 → 준비 완료 순서로 이동합니다. 이전 단계로 돌아가도 작성한 값을 유지하며, X나 ‘바로 둘러보기’로 닫을 수 있습니다.

‘다시 보지 않기’는 이 브라우저의 저장소에만 저장됩니다. 저장소를 사용할 수 없는 브라우저에서는 현재 접속 동안만 적용됩니다. 사이드바의 ‘처음 이용 안내 다시 보기’로 수동 재열기가 가능합니다. 다시 자동으로 보려면 다시 연 안내에서 ‘다시 보지 않기’를 해제하세요.

생활 설정과 대화는 게스트 세션에만 유지됩니다. 브라우저 재접속·서버 재시작 시 보존을 보장하지 않습니다. 현재 화면은 설정을 URL에 새로 저장하지 않습니다. ‘내 설정·분석 기록 보관하기’는 로그인 준비 안내이며 계정 저장 성공을 뜻하지 않습니다.

### 4-2 날짜와 지도

날짜 버튼은 오늘부터 5일 뒤까지입니다. 선택한 날짜에서 아직 지나지 않은 연속 3시간의 평균 가능성을 비교하며, 기준에 맞는 구간이 없으면 추천이 없다고 표시합니다. 그래프에서 시각을 선택하면 지도가 해당 시각을 보여줍니다. 과거 시각을 탐색하는 것과 향후 사용 계획 추천은 다릅니다.

‘전력 흐름’의 지도 색은 제주 전체 예측, 원 크기는 권역별 재생에너지 설비 규모입니다. 지역별 잉여 전력량을 계산한 지도가 아닙니다. ‘충전소 찾기’에서는 전체·급속 충전소를 탐색합니다. ‘내 주변 충전소’는 사용자가 위치를 허용한 경우에만 동작하며 위치 계산은 브라우저 안에서 수행하고 서버에 보내거나 저장하지 않습니다. 제주 밖·권한 거부·위치 실패 시 설정한 동네 등 대체 기준으로 안내합니다.

### 4-3 내 생활 설정과 질문

‘내 생활 설정’의 ‘설정 변경’에서 동네·차종·평일 외출시간·요금제를 바꿉니다. 변경은 현재 세션의 다음 질문부터 반영하며 기존 답변을 자동 재계산하지 않습니다. 돌아오는 시각은 나가는 시각보다 늦어야 하고 자정을 넘는 외출 일정은 현재 설정에서 지원하지 않습니다.

‘생활 계획’에는 ‘이번 주 언제가 좋아?’, ‘전기차 충전’, ‘왜 생기는 거야?’, ‘지난 예보 맞았어?’ 네 가지 빠른 질문이 있습니다. 직접 질문할 때는 사용할 기기·날짜·시각·외출 조건을 함께 적으면 좋습니다.

- “내일 10시부터 15시까지 세탁기 돌리고 싶어.”
- “9시 출근 6시 퇴근인데 전기차 언제 충전해?”
- “전기차 90% 남았어. 충전 언제 해?”
- “노형동 근처 급속 충전소 알려줘.”

질문에 명시한 조건을 기본 설정보다 우선합니다. 예약 가능한 기기와 직접 조작이 필요한 기기를 구분하고 전기차는 집·외출 중 목적지 충전 후보를 나눕니다. 현재 충전량이 계산 목표인 80% 이상이면 추가 충전 일정을 만들지 않습니다. 80%는 이 서비스의 계산 기준이며 차량별 권장 충전량을 대신하지 않습니다.

### 4-4 근거와 캘린더

‘근거 보기’에서 도구 입력·결과·출처와 응답 방식을 확인합니다. 유효한 추천 시간에 표시되는 ‘구글 캘린더’는 저장 화면을 여는 링크이며 사용자가 최종 저장합니다. ‘아이폰·아웃룩 (.ics)’은 내려받아 캘린더 앱에서 가져옵니다. 파일 다운로드만으로 기기에 일정이 등록되지는 않습니다.

ICS 파일에는 10분 전 알림이 포함됩니다. Google Calendar 알림은 사용자 설정을 따르므로 저장할 때 확인하세요. 지난 추천은 저장 후보에서 제외하고 서비스 자체에서 알림을 발송하지 않습니다.

### 4-5 데이터 및 연결 상태

사이드바는 ‘연결 설정’, ‘예측 자료’, ‘제주데이터허브 자료’로 상태를 구분합니다. ‘보유’는 파일이 있다는 의미이며 최신성이나 실시간성을 보장하지 않습니다. 기상예보는 ‘최신’, ‘저장 자료’, ‘갱신 실패’, ‘자료 없음’을 구분하고 발표 시각을 표시합니다. 전력가격 기록의 ‘갱신 필요’와 참고 예측 안내도 함께 확인하세요.

## 5 데이터 갱신과 재학습

기본 체험에 재수집·재학습은 필요하지 않습니다. 아래 명령은 데이터·모델·보고서를 변경하므로 기존 파일을 별도 보관하고 필요한 단계만 실행하세요. 자동 수집은 각 제공처의 권한·한도·이용조건을 따릅니다.

| 목적 | 프로젝트 루트에서 실행 | 필요 조건 |
|---|---|---|
| 제주 SMP 수집 | `python collect_smp.py` | 인터넷 |
| 허브 API 자료 수집 | `python collect_hub.py` | 허브 키·데이터 접근 권한 |
| 허브 파일 정리 | `python prepare_files.py` | 877·123·472 원본 파일 |
| ASOS 과거 관측 수집 | `python collect_weather.py history` | ASOS 권한·키 |
| 모델 학습·평가 | `python train.py` | 학습 가능한 SMP·기상·허브 자료 |
| 단기예보 수집 | `python collect_weather.py forecast` | 공공데이터포털 권한·키 |
| 중기예보 수집 | `python collect_weather.py mid` | 중기예보 활용신청·키 |

허브 전체 수집 대신 `--only 862`처럼 데이터 번호를 선택할 수 있습니다. 각 수집기의 옵션은 `--help`로 확인하세요. 원본 파일 위치와 전처리는 [데이터 명세](data_spec.md)에 있습니다.

화면은 기상예보 갱신 확인 결과를 최대 30분 캐시하며 단기예보가 기본 4시간 이상 오래되고 키가 있으면 갱신을 시도합니다. 중기예보도 별도로 확인합니다. 실패하면 사용할 수 있는 저장 자료 또는 참고 모델로 이어가지만 최신 예보 확보를 보장하지 않습니다. SMP와 허브 자료는 이 기상 갱신만으로 자동 수집되지 않습니다.

저장 모델이 없거나 버전이 맞지 않아 읽을 수 없으면 `predict.load_bundle()`이 재학습을 시도합니다. 필요한 자료·권한·디스크 쓰기 권한이 없으면 실패할 수 있으며, 모델과 평가 보고서가 바뀔 수 있습니다.
