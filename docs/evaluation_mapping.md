# 평가기준 대응표 — 제주 잉여전력 도우미

심사 항목마다 **무엇을 했는지**와 **어디서 확인할 수 있는지**를 짝지어 정리했습니다.
(평가기준 출처: DAKER 「제주 AI·빅데이터 활용 AI Agent 개발 챌린지」 대회 페이지. 표 형식은 팀원 C의 `TIMEFLOW_JEJU_MVP/docs/EVALUATION_MAPPING.md`를 따랐습니다.)

## 1. 항목별 대응

| 평가 항목 (배점) | 우리가 한 것 | 확인할 곳 (증거) |
|---|---|---|
| **주제 타당성·창의성 (15)** | 제주는 재생에너지가 남아 발전기를 멈추는 출력제어가 잦습니다. 풍력은 2021~2024.5 동안 336일, 약 73,224MWh가 버려졌습니다. 이 낮 시간 전기를 **도민 생활(빨래·충전)로 옮기도록** 며칠 앞서 알려 주는 생활형 Agent입니다. 도민은 kWh를 모른다는 점에서 출발해, 생활 언어("오늘 저녁에 세탁기 돌리려고")를 시간·전력량 계산으로 바꿉니다. 기대효과는 가정 기기와 전기차 시나리오로 계산했습니다(보통 시나리오: 잉여일 하루 122 MWh, 버려진 풍력 하루 평균의 약 56%). 시간 추천 답 끝에는 **참여로 이어지는 길**(계시별 요금제 확인 창구, 전기차는 플러스 DR)을 붙여, 알려 주기에서 실제 참여로 넘어가는 입구 역할을 합니다(결과 설명자료 7-2). | `docs/result_report.md` 1장·4-2절·7장, 그림 6(`reports/figures/report_6_grid.png`) |
| **필수 제주 데이터 활용 (20)** | 제주데이터허브 **7종**을 실제로 받아 씁니다: 579(일별 기상 → 학습 변수), 862(충전소 → 동네 충전소 찾기·지도), 1225·1226(충전 이력 → **충전소 추천 순서**: 낮에 붐볐거나 대기가 잦았던 곳은 뒤로 보내고 이유를 말함, 도민 충전 시각), 877(기후 → 일사·바람 설명), 123·472(태양광·풍력 설비 → 설비 증가 설명, 화면의 권역별 설비용량 지도). 외부 데이터(EPSIS SMP 정답, 기상청, 한국전력거래소 계통 기록)와 **같은 시각 기준으로 연결**했습니다. | `docs/data_spec.md` 1~3장, `docs/result_report.md` 4-1-1, 답마다 붙는 '🏝️ 이 답에 쓰인 제주데이터허브' 배지, 근거 보기 표의 '낮 이용(허브 1226)' 칸 |
| **AI Agent 기술성·완성도 (25)** | Gemini 3.5 Flash-Lite가 **도구 11개**를 함수 호출로 골라 부르고, 도구 결과로만 답합니다. 질문마다 오늘 날짜·이번 주·예보 범위를 지침에 새로 넣고, 이어지는 대화(최근 3번)를 이해합니다. 오류·한도 초과 때는 다시 시도한 뒤 **규칙 기반 모드로 자동 전환**합니다. 예측은 HistGradientBoosting으로 하고, 날짜 PR-AUC 0.651은 무작위 0.165의 약 4배입니다. 단기예보가 없는 3~5일 뒤는 **중기예보로 따로 학습한 중기 모델**을 써서 참고치(0.39)를 0.52(큰 예보 오차를 넣었을 때)로 올렸습니다. | `agent.py`(지침 `_system_prompt`, `_chat_openai`, `_post_retry`), `tools.py`(`TOOL_SPECS`), `reports/metrics.json`, `reports/llm_eval.md` |
| **편의성·실용성 (25)** | 생활 언어 이해: 기기 사전 16종(공인·제조사 자료)으로 걸리는 시간·전력량을 계산합니다. 원하는 시간에 남는 전기가 없으면 솔직히 말하고 더 나은 때와 예약 기능을 권합니다. 전기차는 배터리 %만, 보일러는 연료 종류만 묻습니다. 출근 일정을 반영하고(팀원 C 방식), 노트북 한 화면 대시보드(왼쪽 5일 예보 카드·지도 2종·**시간대별 잉여전력 예보 카드**(그래프를 누르면 그 시각 선택, 제목 줄에 추천 시간대), 오른쪽 내 정보·대화, 다크 모드 대응), **잉여 예보 지도**(권역별 설비용량 × 고른 시각의 가능성), **충전소·풍력발전소 지도**(팀원 B 방식)와 충전소별 카카오맵 위치·길찾기 링크, **내 정보 저장**(동네·차종·출퇴근을 한 번만 입력), **캘린더 알림**(추천 시간대를 일정으로 저장, 10분 전 알림), **내 주변 충전소**(카카오맵, GPS는 브라우저 안에서만, 제주 밖·실패하면 빨간 안내와 저장한 동네, 카카오맵 길찾기), 근거 보기(표·그래프·지도)를 갖췄습니다. 시간을 "12시~14시"처럼 말합니다. | 웹 화면(팀 시연 주소), `appliances.py`, `docs/manual.md`, `docs/result_report.md` 4장 |
| **신뢰성·재현성 (15)** | 학습에 쓰지 않은 기간(2026.1.1~11.17)으로 평가하고, 단순 규칙·과거 비율 기준선과 비교했습니다. 정답(SMP 0원 이하) 시간이 실제 출력제어 시간과 겹침을 따로 확인했습니다(그림 6). **예보가 틀릴 때의 성능**도 오차를 섞어 시험했습니다(보통 오차에서 관측 대비 96% 유지, 그림 7). **pytest 자동 시험 137개**(팀원 C 방식, 키·인터넷 없이 `python -m pytest`)와 Gemini 27문항 시험(**27/27 통과**, 2026-11-19)이 있습니다. 답에는 출처를 붙이고, 예보 범위(5일) 밖·지난 날짜는 예보하지 않습니다. 한계를 따로 밝혔습니다. | `tests/`(`python -m pytest`), `run_scenarios.py` → `reports/scenario_results.md`, `run_llm_eval.py` → `reports/llm_eval.md`, `experiments/forecast_error_test.py` → `reports/forecast_error_test.md`, `docs/result_report.md` 5·6·8장, `requirements-tested.txt` |
